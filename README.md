# Доступность по замерам Яндекс Карт

Метод из «прописных истин» (§7): 50 точек на дорожной сети, замеры времени в пути до центра
в Яндекс Картах, калиброванное поле времени по сети OSM и изохроны 15/30/45 мин.

## Конвейер

```
python -m yandex_accessibility graph yaroslavl        # граф OSM, 40 км вокруг центра
python -m yandex_accessibility points yaroslavl       # 50 точек: 8 направлений × 6 колец + 2 близкие
python -m yandex_accessibility links yaroslavl --date 2026-10-12
#   data/yaroslavl/points_yandex.html: открыть ссылки, вписать «минуты|км», скачать CSV
#   сохранить как data/yaroslavl/travel_times.csv (point_id,slot,minutes,km)
python -m yandex_accessibility isochrones yaroslavl --water
```

Срезы суток: 03:00 (свободный поток), 08:00 (утренний пик), 11:00 (день), 18:00 (вечерний пик).
Замеры — прогноз Яндекса на выбранный день по типичной загруженности, а не фактический трафик.

## Как считается

1. Точки: узлы степени ≥ 6 в самой большой сильно связной части графа; `straight_km` — фактическое
   расстояние по прямой, `snap_km` — сдвиг привязки (где нет дорог, он может достигать нескольких км).
2. Поле времени (`field.py`): время по дорожной сети до центра + распространение вне дорог по сетке
   250 м со скоростью 20 км/ч. С ключом `--water` водные полигоны OSM непроходимы, кроме мостов
   (клеток с дорогой), поэтому водоёмы не «перепрыгиваются».
3. Калибровка (`calibrate.py`): t_Яндекс = a·t_сеть + b по МНК; для каждого среза выбирается сценарий
   сети (free/rush) с меньшей ошибкой leave-one-out; для сравнения считаются радиальная кривая
   «время от расстояния» и пространственная интерполяция точек.
4. Изохроны (`isochrones.py`): замкнутые «острова» < 80 км² не рисуются, кроме петли вокруг центра.

## Допущения, которых нет в описании метода

- Скорости по классам дорог и множители часа пик (`config.py`) — разумные значения по умолчанию,
  не взятые из исходного кода. Масштаб и сдвиг всё равно подбирает калибровка.
- Центр Ярославля — тестовый (Советская площадь, приблизительно), в отличие от четырёх городов из §1.

## Проверка

`pytest tests` — сквозной тест на синтетическом городе в координатах Ярославля: 50 точек, поле с рекой и
мостом, калибровка четырёх срезов (выбор free/rush), рисунок 1×4, ссылки и разбор времени. Реальных
данных OSM и замеров Яндекса тест не использует.

## 100 точек на УДС Ярославля (слой gpkg)

```
python -m yandex_accessibility uds data/yaroslavl/uds.gpkg --out results/yaroslavl --date 2026-10-20
```

Центр — Богоявленская площадь (центроид одноимённых сегментов слоя). Граф строится из слоя УДС
(`one_way` учитывается, пешеходные улицы исключены, берётся самая большая сильно связная часть).
Состав: 8 направлений × кольца 3/8/13/18/23/28 км + 2 близкие (З-1.5, В-1.5), посёлки/ЖК
(вес = длина дорог × тип; СНТ — 0,4), остальное — заполнение пробелов (на замену выбросам после первой
калибровки). `holdout=True` — точки вне подгонки (~20 % внутри каждой роли). `snap_km` — сдвиг привязки.
Слой покрывает в основном город, поэтому часть дальних колец (18–28 км) пропущена и заменена заполнением.

Замеры: 08:00 и 11:00 — из точки в центр, 18:00 — из центра в точку. Ссылки — `yandex_links.csv`,
ввод «мин|км» — `points_yandex.html`.

Изохроны по графу УДС без калибровки: `python -m yandex_accessibility uds-iso data/yaroslavl/uds.gpkg results/yaroslavl/isochrones_uds.png`
(скорости по классам — допущение, воды и общественного транспорта в этой версии нет).
