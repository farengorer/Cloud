# uds_calculated.gpkg — исходный слой УДС с расчётными значениями

Слой `uds_calculated`: все 8 412 сегментов исходного слоя УДС (исходная геометрия MultiLineString, EPSG:4326 и все исходные
атрибуты: `name`, `classid`, `cat`, `one_way`, `maxspeed`, `lanes`, `barrier` и т. д.) плюс расчётные поля ниже.
Расчётные значения — по рёбрам графа УДС (один сегмент ↔ одно ребро между узлами). Если сегмент не попал в граф, поля пустые.

| Поле | Единицы | Описание |
|---|---|---|
| `in_graph` | логическое | Сегмент учтён в расчётном графе (True — 8 185 из 8 412). Не учтены: пешеходные улицы (86), сегменты вне главной связной части сети и части со слишком короткой геометрией. |
| `t_0800` | мин | Время из точки (сегмента) в центр (Богоявленская пл.) при отправлении в 08:00, шкала Яндекс Карт, «от двери до двери» (включает ~3–4 мин «накрутки» на старт и посадку). |
| `t_1100` | мин | То же в 11:00 (свободный поток). |
| `t_1800` | мин | Время из центра в точку (сегмент) в 18:00. Направление противоположное: напрямую с `t_0800` не сравнивать. |
| `gap_km` | км | Расстояние по сети до ближайшего замера Яндекса. Чем больше, тем менее надёжно значение; при > 3 км `t_*`, `ratio`, `diff_min` пустые. |
| `ratio` | × | Во сколько раз утром (08:00) дольше, чем днём (11:00): интерполяция замеров по сетевому расстоянию. |
| `diff_min` | мин | Потеря утром: время 08:00 минус 11:00, интерполяция замеров по сетевому расстоянию. |
| `vc_base` | — | Загрузка утром в пик (поток/пропускная способность) в базе (существующее население и МПТ); модельная оценка, пропускная способность допущена по классу и числу полос. |
| `vc_s1`, `vc_s2` | — | То же в сценариях «срезка» (+33 тыс. чел.) и «полный проект» (+180 тыс.). |
| `d_s1`, `d_s2` | мин | Прирост времени до центра утром в сценариях «срезка» и «полный проект» (сеть без изменений), шкала Яндекс. |
| `cap` | авт/ч | Допущенная пропускная способность направления (класс дороги × число полос), не из исходных данных. |

Данные замеров: 140 точек, 2026-10-20, первый (самый быстрый) маршрут на авто; 08:00 и 11:00 — в центр, 18:00 — из центра.
Точность `t_*` на независимых точках, RMSE: 5,0 / 2,7 / 3,2 мин (08:00 / 11:00 / 18:00).
