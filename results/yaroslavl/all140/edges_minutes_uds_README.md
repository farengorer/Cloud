# edges_minutes_uds.gpkg — описание слоя

Слой рёбер улично-дорожной сети (УДС) Ярославля с рассчитанным временем в пути до центра и из центра.
Центр — Богоявленская площадь (57.6226, 39.8879). Формат: GeoPackage, слой `edges`, СК EPSG:4326.
Геометрия — прямая линия между концами ребра (не исходная кривая УДС). Одна запись = одно ребро без учёта направления
(8 140 записей); для двусторонних дорог значения усреднены по двум направлениям.

## Поля

| Поле | Тип | Единицы | Описание |
|---|---|---|---|
| `rank` | целое | — | Класс дороги (ранг): 6 — а/д федерального значения; 5 — региональные/межмуниципальные и магистральные улицы общегородского значения; 4 — магистральные улицы районного значения и съезды развязок федеральных/региональных; 3 — улицы местного значения и съезды городских развязок; 1 — квартальные проезды и прочее. Пешеходные улицы в слое отсутствуют. |
| `gap_km` | число | км | Расстояние по сети от ребра до ближайшей точки замера Яндекса (максимум по двум концам ребра). Чем больше, тем менее надёжно значение. |
| `t_0800` | число | мин | Время поездки **из точки (ребра) в центр** при отправлении в 08:00. Шкала Яндекс Карт, «от двери до двери» (включает около 3–4 мин «накрутки» Яндекса на старт и посадку). |
| `t_1100` | число | мин | То же при отправлении в 11:00 (свободный поток). |
| `t_1800` | число | мин | Время поездки **из центра в точку (ребро)** при отправлении в 18:00. |

Значения `t_*` пусты (NULL), если `gap_km` > 3 км (нет замеров рядом, значение не оценивается).
Для ребра значение = среднее по двум его концам. Диапазоны: `t_0800` 2–48, `t_1100` 4–39, `t_1800` 4–39 мин.

## Как получено

- Замеры Яндекс Карт, 140 точек, дата 2026-10-20 (вторник), первый (самый быстрый) маршрут на авто.
  Направления: 08:00 и 11:00 — из точки в центр; 18:00 — из центра в точку.
- Время ребра: модель времени по графу УДС (длина / скорость по классу дороги, свободный поток для 11:00, пик для 08:00 и 18:00),
  калибровка `T_Яндекс ≈ a·T + b` по контрольным точкам для каждого среза отдельно, подгонка по относительной ошибке,
  групповая поправка (класс дороги × зона от центра) и локальная поправка по сетевому расстоянию.
- Точность на независимых (holdout) точках, RMSE: 08:00 — 5,0 мин; 11:00 — 2,7 мин; 18:00 — 3,2 мин.

## Ограничения

- Калибровка идёт по поездкам «в центр» и «из центра»: поперечные маршруты между районами замерами не проверялись.
- Для рёбер в центре и далеко от замеров (`gap_km` велик) точность ниже средней.
- Значения — прогноз Яндекса на указанную дату по типичной загруженности, а не фактический трафик.
- Загородные рёбра за пределами городского слоя могут быть экстраполяцией.
- `t_0800` и `t_1800` нельзя сравнивать напрямую как «утро/вечер»: направления разные (в центр / из центра).
