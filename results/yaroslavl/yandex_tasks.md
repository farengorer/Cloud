# Замеры Яндекс Карт: Ярославль, 100 точек

Центр: **Богоявленская площадь**, `57.622564, 39.887852` (широта, долгота). Дата отправления: **2026-10-20** (вторник).

## Задание

Для каждой из 100 точек и каждого из трёх срезов открыть ссылку из таблицы в веб-версии Яндекс Карт (вид транспорта: автомобиль) и считать:

| Срез | Направление |
|---|---|
| 08:00 | из точки в центр |
| 11:00 | из точки в центр |
| 18:00 | из центра в точку |

Всего 300 ссылок. Для каждой взять **первый (самый быстрый) маршрут**:

1. `minutes` — время в пути, минуты (целое или с точкой; «1 ч 5 мин» = 65).
2. `km` — длина маршрута, км.
3. `departure` — подпись «Отправление …» из карточки маршрута (подтверждает, что Яндекс принял заданное время). Если подписи нет, оставить пустым и поставить `status=no_departure`.
4. `status` — `ok`, `no_route` (маршрута нет), `no_departure` (время не принято), `error`.

Правила:
- Направление менять нельзя: ссылки уже собраны под нужное направление.
- Все замеры на одну дату, ничего не пересчитывать на другие дни.
- Ночные замеры не нужны.
- Если страница отдаёт капчу или «limited», не придумывать значения: поставить `status=error` и сообщить.
- Работать частями по срезам (сначала 08:00, затем 11:00, затем 18:00), чтобы не упереться в лимиты браузера.

## Формат ответа

CSV с заголовком (файл `travel_times.csv`):

```
point_id,slot,direction,minutes,km,departure,status
1,08:00,from_center,12,5.4,Отправление в 08:00,ok
```

`direction`: `from_center` или `to_center`. `point_id` и `slot` брать из таблицы ниже.
