# Симулятор государства

Стратегическая игра про развитие городов и агломераций на случайно сгенерированной планете.
Работает в браузере, офлайн. Исходный одностраничный файл разобран на модули TypeScript.

## Запуск

```
npm install
npm run dev          # сервер разработки
npm run build        # проверка типов + сборка в dist/
npm run preview      # посмотреть собранную версию
npm run typecheck    # только tsc
npm run format       # Prettier
npm test             # регрессионные тесты (нужен Chromium)
```

Для тестов нужен Chromium. По умолчанию берётся `/opt/pw-browsers/chromium`, другой путь
задаётся переменной `CHROMIUM_PATH`.

## Устройство

| Модуль | Что внутри |
|---|---|
| `config` | константы и таблицы: размеры карты, виды застройки, действия, параметры |
| `state` | всё изменяемое глобальное состояние (`S`, `rng`, режимы и выделения) |
| `util` | форматирование, шум, мелкие помощники |
| `terrain`, `worldgen` | рельеф, реки, моря, горы, биомы, месторождения |
| `city`, `model` | сетка города, рост, ежемесячный шаг симуляции |
| `actions` | строительство и действия игрока, расходы |
| `economy`, `resources`, `energy` | товары, рынок, цепочки, электростанции |
| `districts`, `borders`, `zones`, `villages`, `agglomerations`, `metro`, `skyscrapers` | карта регионов и присоединение, векторные границы, зоны влияния, сёла, спутники, метро, небоскрёбы |
| `colors`, `draw`, `layers`, `views`, `controls` | отрисовка карты и города, слои, вкладки, элементы управления |
| `saveload`, `multiplayer`, `foreign` | сохранения, онлайн-режим (нужен `window.claude`), иностранные государства |
| `app` | игровой цикл и запуск, `main.ts` связывает модули |

Правила, которые стоит соблюдать:

- Состояние меняют только через сеттеры из `state.ts` (`setS`, `setGhost`…): ES-модуль не позволяет
  присваивать импортированную переменную. Если имя сеттера совпало бы с функцией, он называется
  `assign<Имя>` (например `assignFounding`).
- Подписки на события находятся в функциях `setup*()`. `main.ts` вызывает их в порядке секций.
- Типы пока мягкие (`strict: false`): основные структуры (`S`, города) описаны как словари. Следующий шаг —
  интерфейсы `GameState` и `City`.

## Регионы

На планете государство делится на регионы. На картах версии 4 клетка карты и есть регион
(в среднем около 60 тыс. км², центры расставлены «синим шумом», размеры близки). Свободный регион
присоединяют за 50 млрд плюс 1 млрд за каждые начатые 100 км до ближайшего города от 100 тыс. жителей
(`regionClaimCost` в `districts.ts`). Внутри кода клетка по-прежнему называется `district`, а у региона
есть список `districts` из одной клетки. Так остаются читаемыми сохранения и карты старых версий
(1–3), где регион состоял из нескольких районов, а цена присоединения прежняя (15 млрд и 1 млрд за 10 км).

Границы между регионами рисует `borders.ts`: из рёбер растра собираются ломаные линии, внутренние
вершины сглаживаются, узлы стыков и береговая линия остаются на месте.

## Тесты

`tests/regression.test.ts` проверяет, что симуляция не изменилась. Обычная партия и действия игрока сверяются с исходной версией, планета и территория — с собственным эталоном `tests/golden-planet.json` (их правила менялись намеренно). Он запускает игру в Chromium с
фиксированным `Math.random` и временем, прогоняет сценарии (30 лет на области, 10 лет на планете,
15 лет с действиями игрока) и сравнивает хеши состояния с `tests/golden.json`.

Эталон снят с исходной версии (`legacy/index.html`) командой:

```
node tests/capture-legacy.mjs > tests/golden.json
```

Эталон планеты: `node tests/capture-planet.mjs > tests/golden-planet.json`. Если поведение меняется намеренно, пересоберите эталон и объясните причину в коммите.
`tests/build.test.ts` собирает продакшен-версию и проверяет, что она стартует.

## Что известно

- `legacy/index.html` — исходный файл без изменений. Когда он перестанет быть нужен, его можно удалить:
  он останется в истории git.
- Музыка `music/game-theme.mp3` в репозиторий не входила. Положите файл в `public/music/`.
- Онлайн-режим работает только внутри платформы, которая даёт `window.claude`. Без неё игра
  одиночная.
